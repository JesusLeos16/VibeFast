## Helpers principales

```js
import { streamChat } from "@/lib/openai/chat"
import { generateObject } from "@/lib/openai/structured"
```

- `streamChat(messages)` — chat streaming para UIs interactivas.
- `generateObject(schema, prompt)` — JSON tipado garantizado por el modelo.

## Kickiie AI · seguimiento_v1

La ruta `POST /api/ai/structured` recibe un objeto con `prompt` y devuelve una salida
validada con Zod. El contexto de academia se obtiene de la sesión del usuario;
el cliente no envía `academy_id`.

El contrato incluye `student`, `type`, `summary`, `return_date`, `priority`,
`suggested_action` y `missing_information`.

La interpretación inicial es de solo lectura. Después de seleccionar un alumno,
la pantalla puede pedir confirmación explícita y llamar la tool controlada
`registrar_seguimiento`; el backend vuelve a validar la academia y el alumno
antes de escribir en Supabase.

Configuración de modelos y costo en `config.ai`.
